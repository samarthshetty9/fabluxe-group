# Fabluxe Group Website — Website 1

## What this is

The corporate/group website for **Fabluxe**, which has two separately registered operating companies — **Fabluxe Home Solutions** (electronics) and **Fabluxora Interiors** (home interiors). This site doesn't sell anything; it establishes the group's credibility (history, people, projects, awards, CSR), routes B2B enquiries, and links out to the group's other web properties, including Website 2 (the e-commerce site — separate Lovable project/repo).

**This is a prototype meant to show off the site, not a production build.** No back end is required at this stage, and no specific functional features are required beyond what's needed to demonstrate the concept — the priority right now is getting the requirements and the look right, not wiring up real functionality. See the attached **Project Scope Report** for the full requirements and the attached **Lovable prompt document** for exactly what was asked of the build.

## Run locally

```bash
npm install
npm run dev
```
